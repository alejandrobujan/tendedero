# Tendedero

Τα στιγμιότυπα οθόνης και όσα αντιγράφετε κρεμιούνται σε ένα σχοινί στο επάνω μέρος της οθόνης σας. Αφήστε τον δείκτη στο κέντρο της γραμμής μενού για να εμφανιστούν. Απομακρύνετέ τον για να κρυφτούν.

Δωρεάν εφαρμογή ανοικτού κώδικα για macOS 14 και νεότερο, σε Mac με Apple silicon ή Intel. Λειτουργεί τοπικά, χωρίς λογαριασμό ή αναλυτικά στοιχεία χρήσης.

## Εγκατάσταση και ελληνική γλώσσα

Κατεβάστε την εικόνα δίσκου από τις [εκδόσεις](../../releases/latest) και σύρετε το Tendedero στον φάκελο Εφαρμογές. Εναλλακτικά: `brew install tendedero`.

Η ελληνική μετάφραση περιλαμβάνεται σε build που ενσωματώνει αυτές τις αλλαγές. Το macOS επιλέγει τη γλώσσα βάσει των προτιμήσεών σας. Μπορείτε επίσης να επιλέξετε Ελληνικά ειδικά για το Tendedero από τις Ρυθμίσεις συστήματος → Γενικά → Γλώσσα και περιοχή → Εφαρμογές. Κλείστε και ανοίξτε ξανά την εφαρμογή μετά την αλλαγή.

## Χειρισμός

| Ενέργεια | Αποτέλεσμα |
|:--|:--|
| Κλικ | Αντιγραφή εικόνας ή κειμένου σημείωσης, με τη μορφοποίησή του. |
| Παρατεταμένο πάτημα | Άνοιγμα στη Σήμανση ή επεξεργασία σημείωσης. Σε εγγραφή οθόνης, περικοπή βίντεο. |
| Διπλό κλικ | Άνοιγμα στην Προεπισκόπηση ή άνοιγμα συνδέσμου στον περιηγητή. |
| Δυνατό κλικ | Γρήγορη προβολή. |
| Σύρσιμο σε εφαρμογή | Αποστολή αντιγράφου· το στοιχείο παραμένει στο σχοινί. |
| Σύρσιμο σε φάκελο | Αποθήκευση εκεί και αφαίρεση από το σχοινί. |
| Σύρσιμο στον Κάδο ή κλικ στο × | Αφαίρεση του στοιχείου. |
| Shift και κλικ | Επιλογή πολλών στοιχείων για αντιγραφή, αφαίρεση ή σύρσιμο. Το Esc ή ένα απλό κλικ καθαρίζει την επιλογή. |
| ⌘Z με τον δείκτη στο σχοινί | Αναίρεση αφαίρεσης, καρφιτσώματος ή αποθήκευσης στο Γραφείο εργασίας, ακόμη και για πολλαπλή επιλογή. |
| Διάστημα με τον δείκτη σε φωτογραφία | Γρήγορη προβολή. |
| Delete με τον δείκτη σε φωτογραφία | Αφαίρεση, όπως με το κουμπί στη γωνία της. |
| Δεξί κλικ → Κοινή χρήση | Αποστολή μέσω AirDrop, Μηνυμάτων, Mail κ.ά. |
| Δεξί κλικ → Καρφίτσωμα | Διατήρηση στα αριστερά του κόμπου, χωρίς να εκτοπίζεται από νέα στιγμιότυπα. |
| Δεξί κλικ → Διατήρηση στο προσκήνιο | Προβολή έξω από το σχοινί ενώ εργάζεστε. Το κείμενο σημείωσης μπορεί να επιλεγεί. |
| Finder: δεξί κλικ σε εικόνα ή αρχείο κειμένου → Κρέμασμα στο Tendedero | Προσθήκη στο σχοινί με καρφίτσωμα. |
| Δείκτης πάνω σε φωτογραφία με ενεργή τη μεγέθυνση | Μεγαλύτερη προβολή στο κέντρο της οθόνης. |
| Δείκτης στο κέντρο της γραμμής μενού | Εμφάνιση του σχοινιού σε εκείνη την οθόνη. |
| Κλικ σε στοιχείο της γραμμής μενού | Απόκρυψη του σχοινιού. |
| ⌃⌥T | Εμφάνιση ή απόκρυψη του σχοινιού. |
| ⌃⌥F | Αναζήτηση στο σχοινί. Το Return αντιγράφει το νεότερο αποτέλεσμα. |

Οι συντομεύσεις αλλάζουν από το μενού της εφαρμογής. Η αναζήτηση βρίσκει κείμενο σε στιγμιότυπα οθόνης, σημειώσεις και συνδέσμους, με τοπική αναγνώριση κειμένου στο Mac.

Από την επιλογή «Κρέμασμα όσων αντιγράφετε» ενεργοποιούνται χωριστά εικόνες, κείμενο και σύνδεσμοι. Δεν αποθηκεύονται στοιχεία από πεδία συνθηματικών, περιεχόμενο που οι διαχειριστές συνθηματικών επισημαίνουν ως ιδιωτικό ή περιεχόμενο από άλλη συσκευή μέσω του Καθολικού πρόχειρου.

Η διαχείριση στιγμιοτύπων απενεργοποιεί την αιωρούμενη μικρογραφία και αποθηκεύει τις λήψεις στον φάκελο της εφαρμογής. Οι προηγούμενες ρυθμίσεις επανέρχονται όταν κλείσετε το Tendedero ή απενεργοποιήσετε τη λειτουργία.

## Μεταγλώττιση

Σε macOS, από τον ριζικό φάκελο του αποθετηρίου:

```sh
scripts/build-app.sh
open build/Tendedero.app
```

Απαιτείται το Swift toolchain. Το Xcode είναι προαιρετικό. Κλείστε πρώτα κάθε άλλη εκτέλεση του Tendedero. Τα τοπικά build υπογράφονται ad hoc και το macOS μπορεί να ζητήσει ξανά πρόσβαση στο Γραφείο εργασίας μετά από κάθε build.

Έλεγχος μεταφράσεων: `swift scripts/check-strings.swift`. Περισσότερες τεχνικές οδηγίες στο [CONTRIBUTING.md](../../CONTRIBUTING.md) και στο [αγγλικό README](../../README.md).
